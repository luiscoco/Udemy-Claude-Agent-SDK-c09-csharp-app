No API key is required for the local experiment. Optional live commentary requires your own API key, agent ID and environment ID. It explains the local result; it does not activate the integration discussed in the lesson.

For the optional live path, set your API key, then run dotnet run --project src/LessonC09.Web -- setup if you do not already have resource IDs. 1 · Load scenarios and collect input

The interactive LabWorkbench component renders editable fields for the selected scenario. Clicking Run travels over the Blazor Server circuit straight to LabRunner; no browser fetch is involved. The same runner also backs POST /api/run for scripts.

private async Task Run(bool live)
{
    running = true;
    try
    {
        var input = Read();
        if (live) commentary = await Lab.RunLiveAsync(input);
        else result = await Lab.RunLocalAsync(input);
    }
    catch (Exception error) when (error is LabBusyException or LessonInputException or LiveObservationException or JsonException or FormatException)
    {
        status = error.Message;
    }
    finally { running = false; }
}

public Task<JournalEntry> RunLocalAsync(JsonObject input, CancellationToken ct = default) =>
    Exclusive(async () =>
    {
        var entry = new JournalEntry(Guid.NewGuid(), DateTimeOffset.UtcNow, StreamRecoveryLesson.Number, StreamRecoveryLesson.Run(input));
        Directory.CreateDirectory(Path.GetDirectoryName(JournalPath)!);
        await File.AppendAllTextAsync(JournalPath, JsonSerializer.Serialize(entry, Json) + "\n", ct);
        return entry;
    });

private async Task<T> Exclusive<T>(Func<Task<T>> work)
{
    if (!busy.Wait(0)) throw new LabBusyException();
    try { return await work(); }
    finally { busy.Release(); }
}

4 · Optional live commentary

This separate request asks a text-only Claude session to explain the local evidence. It does not perform the lesson's external integration.

The host creates a bounded text-only session with the Anthropic C# SDK, connects the event stream before sending the user message, and reports provider evidence. Read the cleanup path before interpreting failures.

Source: src/LessonC09.Web/Live/ManagedAgentCommentary.cs

var session = await client.Beta.Sessions.Create(new SessionCreateParams
{
    Agent = new BetaManagedAgentsAgentWithOverridesParams
    {
        ID = config["CLAUDE_MANAGED_AGENT_ID"]!, System = System,
        Tools = [], McpServers = [], Skills = [],
    },
    EnvironmentID = config["CLAUDE_MANAGED_ENVIRONMENT_ID"]!,
    Budget = new BetaManagedAgentsBudgetLimit { MaxListCost = new() { Amount = "10", Currency = "USD" } },
}, deadline.Token);

// Stream before send: awaiting the raw response returns once the stream is connected.
using var stream = await client.WithOptions(o => o with { Timeout = TimeSpan.FromSeconds(60) })
    .Beta.Sessions.Events.WithRawResponse.StreamStreaming(session.ID, new EventStreamParams(), deadline.Token);
await client.Beta.Sessions.Events.Send(session.ID, new EventSendParams { Events = [ /* user.message */ ] }, deadline.Token);

When the stream closes without an answer, the observer reads persisted history and deduplicates by event ID: the lesson's recovery rule applied to a real session. It never re-sends the prompt or creates another session. On failure, the host sends user.interrupt and reports that the stop is unconfirmed.

await foreach (var streamEvent in stream.Enumerate(deadline.Token))
    if (observer.Deliver(JsonSerializer.SerializeToElement(streamEvent))) break;

if (observer.Answer.Length == 0)
{
    var page = await client.Beta.Sessions.Events.List(session.ID, new EventListParams(), deadline.Token);
    await foreach (var persisted in page.Paginate(deadline.Token))
        observer.Recover(JsonSerializer.SerializeToElement(persisted));
}

What the evidence proves

Executes a recovery reducer over authored history/live records. No reconnect or remote mutation is claimed by the local experiment. Each run starts from a fresh local seed. The run journal stores results, not production workflow state.

Check the displayed outcome and source together. A rendered answer alone does not prove that a tool ran, a remote operation succeeded, or work was cancelled.
